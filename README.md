# Бар BI Lite WebApp v2

Мобильный Telegram WebApp / статический сайт без backend.

## Что умеет

- Загружает ОСВ `.xlsx/.xls` прямо в браузере.
- Загружает прайс-листы поставщиков.
- Автоматически подтягивает поставщиков из прайсов.
- Если поставщик не найден — ставит `Прочее`.
- Считает дашборд, стопы, оверстоки, ABC-анализ, топы и заявку.
- Заявка по поставщику формируется в виде: `Наименование | Остаток | Заявка`.
- Для каждого поставщика можно настроить:
  - срок доставки;
  - на сколько дней закупаемся;
  - страховой запас.
- Последняя обработанная ОСВ, поставщики и настройки сохраняются в `localStorage` браузера.

## Важно про хранение

Файлы Excel как файлы не хранятся. Сайт сохраняет только обработанные данные в `localStorage`.
Это нормально для версии без backend. Если браузер очистит данные сайта или localStorage переполнится — файлы нужно будет загрузить заново.

## Как открыть

Просто открой `index.html` в браузере или залей папку на GitHub Pages.

## Для Telegram WebApp

В BotFather укажи URL страницы GitHub Pages как WebApp URL.
