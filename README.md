# BAR BI Lite WebApp v4 Supplier Hard Fix

Полностью статический мобильный WebApp для Telegram/GitHub Pages. Все файлы обрабатываются локально в браузере.

## Что исправлено

- Поставщики больше не подтягиваются из колонок `Артикул` и числовых значений.
- Парсер прайса ищет только точную колонку `Поставщик` и колонки `Наименование`.
- Старые ошибочные поставщики-цифры автоматически очищаются при загрузке приложения.
- Добавлена кнопка **Очистить поставщиков** в бургер-меню.
- `Прочее` остается как поставщик по умолчанию, если товар не найден в прайсах.

## Как использовать

1. Открой `index.html` или залей папку на GitHub Pages.
2. В бургер-меню нажми **Очистить поставщиков**.
3. Загрузи прайс-лист поставщиков.
4. Загрузи ОСВ.
5. Открой вкладку **Заявка** и выбери поставщика.

## Важно

Excel-файлы как файлы не хранятся. В localStorage сохраняются только обработанные данные и настройки.
