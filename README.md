# BAR BI Lite WebApp v5

Мобильный Telegram WebApp / PWA без backend. ОСВ и прайсы обрабатываются локально в браузере.

## Что добавлено в v5

- Ручная привязка поставщика к товару прямо в заявке.
- Редактор заявки: можно менять количество к заказу.
- Экспорт заявки по поставщику только в формате `Наименование | Количество`.
- История последних ОСВ через `localStorage` — сохраняются обработанные данные, не исходные Excel-файлы.
- PWA-режим: можно установить сайт на телефон как приложение.
- Улучшенная мобильная шапка WebApp.

## Важно про хранение

Файлы `.xlsx` как файлы не сохраняются. В `localStorage` хранятся только обработанные JSON-данные, настройки поставщиков, ручные привязки и история последних загрузок. Это нормально для версии без backend.

## Запуск

Открой `index.html` локально или залей папку на GitHub Pages.
